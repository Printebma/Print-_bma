Ainda não configurado.

Como ativar

  1. Crie um projeto gratuito no Supabase.
  2. Crie as tabelas usando o SQL fornecido no arquivo SUPABASE_SETUP.sql desta versão.
  3. Em Project Settings → API, copie a URL e a chave anon/public.
  4. Cole aqui e toque em “Salvar conexão”.

O app continua funcionando offline. A nuvem entra como sincronização, não como substituição do armazenamento local.
